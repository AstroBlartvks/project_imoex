### LSTM 

- [x] Архитектура (как в статье GINN):
  - 3 LSTM слоя, hidden_size=256
  - Dropout между слоями
  - 2 Linear слоя (256→128, 128→1)
  - BatchNorm + ReLU
- [x] Train loop: AdamW, MSE loss, 300 эпох
- [x] Rolling forecast на test set
- [x] Метрики: MSE, MAE, R²
- [x] График: LSTM vs реальность

### Transformer 

- [x] Архитектура:
  - Linear embedding (1 → d_model=64)
  - Positional encoding
  - TransformerEncoder (nhead=4, num_layers=2)
  - Linear head (d_model → 1)
- [x] Тот же train loop что и LSTM
- [x] Rolling forecast на test set
- [x] Метрики + график

### GINN - гибрид 

- [ ] Та же LSTM архитектура что в Этапе 2
- [ ] Модифицированный loss:
  ```
  Loss = λ · MSE(σ²_real, σ²_GINN) + (1-λ) · MSE(σ²_GARCH, σ²_GINN)
  ```
- [ ] Параметрический подбор λ (0, 0.01, 0.05, 0.1, 0.5, 1.0) на val set
- [ ] GINN-0 (λ=0) как отдельная модель
- [ ] Rolling forecast + метрики + график
